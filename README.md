# GymCrowd  

## Tagline  
A real-time gym tracker to help students avoid peak hours through live occupancy updates.  

---

## Repositories  
- **Frontend (Android)**: [GitHub Link](https://github.com/CamdenKeller/GymCrowd/tree/new-master)  
- **Backend**: [GitHub Link](https://github.com/AdeebK1129/GymCrowd-backend)

---

## App Description  
GymCrowd is a mobile application built to help students plan their workouts by providing **live gym occupancy data**. By tracking real-time crowd levels, users can identify the best times to visit and avoid peak-hour congestion.  

**Key Features:**  
- Real-time gym crowd tracking via web scraping of the Connect2Connect API  
- Secure login/signup with input validation and hidden password fields  
- Scrollable exercise list with the ability to favorite items  
- Optimized backend integration to support **500+ concurrent sessions** under load  

---

## Tech Stack  
- **Language:** Kotlin  
- **Framework:** Jetpack Compose  
- **Architecture:** Model–View–ViewModel (MVVM)  
- **IDE:** Android Studio  
- **Backend:** Custom API endpoints
